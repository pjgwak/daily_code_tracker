요약

관찰된 경향
  1. FINAL_V2를 ver3와 비교하면 8/20만 2% 안이다. ver3는 ver2보다 fwd 1–5에서 크게 다르고(1–2: 0.096 → 0.084, 4–5: 0.181 → 0.165), mid는 전체적으로 1–3% 높다. 이 차이가 사용자가 받은 계통 오차 그림의 fwd 1–2 NP 14.6%, 4–5 8.5%다.
  2. NP 계통 = |ΔB|/B, PR 계통 = |ΔB|/(1−B)이므로 B 상대 차이를 줄이면 둘 다 따라온다. 계통 오차를 고르게 하려면 허용 |ΔB|가 B에 비례해야 한다(2%면 fwd 1–2에서 0.0017, 14–20에서 0.008).
  3. mid는 7–8만 다른 빈과 반대로 움직인다. 평균·폭·구성비를 MC 공분산으로 함께 묶는 joint 제약에서만 2% 안이 되는데, 세기 k를 키우면 7–8은 내려가고 8–9는 올라가서 한 k로 둘 다 넣을 수 없다. 오전에는 7–8 ×64, 8–30 ×384의 2단 계단(최대 1.8%)으로 정했고, 오후에 1% 목표로 세기를 빈별로 정했다(7/8이 1% 안, 8–9 +1.10%). 16–20(음수)과 20–30(모든 규칙에서 +0.3% 이상)은 어느 제약 가족에서도 반대로 움직여 단조 계단으로는 1% 안이 되지 않는다.
  4. fwd 5–10은 6–7(대부분 −5~−12%)과 8–9(+2~+10%)가 반대이고 3–5도 3–4와 4–5가 반대라 한 규칙이 불가능하다. S/B가 좋아질수록 PR 해상도 제약을 단계적으로 푸는 사다리로 정했다: 평균은 8 GeV까지 MC 고정, 그 위는 자유; 폭은 core 고정(3–7) → MC 오차 ×1 제약(7–8) → 모델 오차 제약(8–10) → joint ×16(10–20); NP는 5 GeV 아래 MC 제약, 위는 가장 긴 수명 자유.
  5. fwd 1–2는 규칙 공간에 큰 불연속이 있다(배경 자유 −4.7% vs sideband 제약 +8%; PR 폭 MC 오차 ×8 → ×10에서 +6.0 → −2.6%). 연속적으로 움직이는 유일한 후보(PR 자유, NP 2성분 MC 공분산, 배경 자유)가 +2.3%였고, ctau 창을 [−4, 6.5] → [−6, 10] mm로 넓히면 −0.01%다.
  6. fwd 2–3은 규칙 변형 약 100개가 모두 +2.2% 이상이다. 질량 창 상한 3.4는 −0.30%였지만 질량 창을 빈마다 다르게 두지 않기로 해 되돌렸고, PR MC fit 범위 분위수 0.001/0.999 + 구성비 MC 공분산 제약으로 +1.91%에 넣었다. 분위수 의존이 매끈하지 않아(0.0005 +2.54, 0.0008 +2.43, 0.001 +2.10, 0.0012 +2.21, 0.0015 +3.21) 0.001은 국소 최소다.
  7. 배경 질량 처리(창 하한·상한, Chebychev 차수, 질량 조건부 배경)는 모든 빈에서 같은 방향으로 B를 움직이므로 공통 해법이 아니라 빈별 손잡이다. 질량 조건부 배경은 모든 빈에서 B를 올린다(fwd 1–2 +20%p).

점: B/Bver3 − 1, 막대: fit 오차를 같은 상대 단위로 나타낸 것. 녹색 띠는 ±2%.

2% 이내

전파된 수율 계통 오차

최신 nominal(ver3)과 최신 2D fit(FINAL_V4)만 비교. NP 수율 계통 = |ΔB|/Bver3, PR 수율 계통 = |ΔB|/(1−Bver3) (drawing/v3_systematics.py; 사용자가 준 그림과 같은 정의). 왼쪽은 값에 맞춘 확대 뷰, 오른쪽은 y축을 0–5%로 고정한 넓은 뷰. 녹색 띠 2%. 그림을 누르면 원본 크기로 열린다.

전체 계통 오차 요약에 2D fit 항목을 더하면

위 그림은 분석 노트의 "Summary of systematic uncertainties in OO" 슬라이드(2026-10-31 업로드)이고, 아래 그림은 그 막대 높이를 픽셀로 읽어(±0.1%p) 같은 패널·같은 y축으로 다시 그린 뒤 주황 막대로 FINAL_V3 2D fit 항목(PR = |ΔB|/(1−B), NP = |ΔB|/B)을 더한 것이다. 검은 계단은 원래 Total, 주황 점선은 Total ⊕ 2D fit(제곱합). FINAL_V4 값이다. 수치는 docs/evidence/syst_summary_figure_values.txt, 그림 코드는 docs/figs/syst_summary_with_2dfit.{png,pdf}.

그룹별 규칙

PR 폭 좌표는 가장 좁은 Gauss 폭 σ₁과 간격 Δᵢ = σᵢ − σᵢ₋₁. "제약 (…)"은 MC 값을 중심으로 하는 Gaussian 제약의 폭. "MC 오차 ×k"는 제약 폭이 MC prefit 오차의 k배. "joint ×k"는 PR 평균·폭·구성비를 MC prefit 공분산 ×k로 함께 제약하는 것으로, 폭 기준 MC 오차의 √k배(×16 → 4배, ×64 → 8배, ×384 → 20배)이고 매개변수 사이 상관은 MC 그대로다. S/B는 final fit의 Nsig/Nbkg. 모든 폭 제약은 MC prefit 오차 이상이다.

fwd 제약을 %로 쓰면

fwd 10–20의 joint ×16은 제약 폭 = 4 × MC prefit 오차. mid와 달리 여기서는 제약이 실제로 폭을 정한다: 폭을 전부 풀면 B가 −6~−11%(10–12 −11.1, 12–14 −6.0, 14–20 −6.9%)로 내려가고 데이터는 core 폭을 MC보다 23–55% 넓게 잡는다(B ≈ 0.4, S/B 1.1–1.6에서 PR 꼬리와 NP 짧은 성분이 바뀜). k 의존: ×1 +1.5/+0.5/+0.1 → ×16 +0.3/−0.2/−0.7 → ×64 −2.3/−1.2/−2.1 → ×256 −7.1/−3.4/−4.4%. 상세 docs/evidence/fwd1020_constraint_width_check.txt.

배경 질량 처리의 효과

  • 최종 규칙을 고정하고 질량 창 하한(2.7, 2.8), 상한(3.4), Chebychev 차수(1–4)를 빈마다 바꿔 prefit부터 다시 돌렸다(체인 114개, docs/evidence/bkg_mass_variants_table.txt).
  • 질량 창 하한을 올리면 모든 빈에서 B가 오른다(2.6 → 2.8: fwd +2~+7%p, mid +1~+3%p). 상한을 내리면 대부분 내려간다(3.5 → 3.4: −0.5~−1.5%p, fwd 1–2만 −1.8%p). 방향은 빈마다 같고 크기만 다르다.
  • Chebychev 차수는 대부분 0.5%p 안에서 B를 바꾼다. 1차는 fwd 2–5에서 prefit χ²/ndf ≥ 2로 탈락.
  • 질량 조건부 배경(27일 시험)은 모든 빈에서 B를 올린다(fwd 1–2 +20%p, fwd 3–9 +3~+6%p, mid +0.2~+1.6%p). 질량 모양을 final fit에서 자유로 두면 1%p 안.

한계

  • 그룹 경계와 제약 강도는 nominal 비교를 보며 정했다. fit 오차는 선택한 모형과 제약에서의 통계 오차이며, 규칙 선택에 따른 계통 오차는 포함하지 않는다.
  • fwd 1–2의 통계 오차는 B의 17%라 2%는 0.12σ이고, ctau 창 선택은 사실상 nominal에 맞춘 것이다. fwd 2–3의 PR MC fit 범위 분위수 0.001과 mid의 빈별 세기도 nominal을 보며 고른 값이다. fwd 2–3에서 B는 NP 평균 수명 제약 중심에 0.01 mm당 약 1.6%p로 민감하다. 논문에는 "저 pT fwd 두 빈은 S/B < 0.1이라 fit 창을 따로 정했다" 정도로만 적고 수치 일치는 쓰지 않는다.
  • mid 7–8과 8–9, fwd 6–7과 8–9, fwd 3–4와 4–5는 같은 규칙에서 반대 방향으로 움직인다. 그래서 세기 계단(mid)과 제약 사다리(fwd)가 필요했다.
  • 계통 오차를 더 평평하게 하려면 빈별 값 대신 y 영역별 그룹 값(최댓값 또는 RMS)을 쓰는 방법이 있다. 현재 빈별 값 범위는 fwd 0.0–2.0%, mid 0.1–1.1%.
