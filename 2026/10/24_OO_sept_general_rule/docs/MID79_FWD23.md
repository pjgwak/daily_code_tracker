## 2. mid 8–9: 시도한 설정

| 설정 계열 | mid 8–9 |

- profile 스캔: 최소는 nominal +5~6%, +2% 지점은 ΔNLL 0.36.
- B와 다른 매개변수의 상관은 모두 |ρ| ≤ 0.27이다.
- MC PR prefit을 시작점 31개에서 다시 fit해도 모두 q₃ = 1.96으로 수렴한다(NLL 차 ≤ 0.001).
- 간격비를 데이터만으로 정하면 0.9–1.3이다. 중심 2.5는 MC도 데이터도 지지하지 않는 값이다.
- ctau 상한을 1 mm로 줄이면 −1.4%가 되지만, 신호 NP의 10.5%가 범위 밖으로 잘린다.
- NP 꼬리 비율 N(1–4 mm)/N(0.3–1 mm)은 데이터 0.158 ± 0.023, MC 0.203이다(−2.0σ). mid 9–10도 0.153 ± 0.027 vs 0.199로 같은 방향이다. sideband 차감에 의존하는 측정이다.

## 3. fwd 2–3: 시도한 설정

| 설정 계열 | fwd 2–3 |

| 단순 규칙 174개, 강도 격자(폭 ×2–8, 구성비 ×1·16, NP ×1–175, bkg ×1·4) | +27% 이상 |
| 배경 구성 5종 (유효 prefit) | +31.6~33.6% |

| NP 모양 MC에 거의 고정 (공분산 ×0.01·0.1) | +27.5% 이상 |
| ctau 범위 20가지 | +22~55% (신호 보존 범위 최선 +22~24%) |
| GPT 설정을 MC 시작점에서 | +23.3% |
| PR 구성비 MC 고정 + 간격비 중심 MC (1.77, 4.88) | +17.6% |
| PR 구성비 MC 고정 + 간격비 중심 GPT (3.6, 12) | +3.0% |

- GPT 설정으로 B를 고정한 profile에는 최소가 하나다(+22~25%). nominal 지점은 2ΔNLL ≈ 5.4이다.
- B와 상관이 큰 매개변수는 PR 재귀 구성비 2번(ρ = +0.54)과 NP 긴 수명(ρ = −0.47)이다. 데이터 fit은 NP 수명을 MC보다 짧게 원한다.
- 간격비를 데이터만으로 정하면 q₃ = 0.0, q₄ = 2.8로 MC(1.77, 4.88)보다 작다. nominal 근처는 MC의 약 2배 중심에서만 나온다.

## 4. 23일 결과의 역추적

23일 campaign의 입력(소스, prefit, knob, 초기값, 범위 파일)을 그대로 쓰고 조건을 하나씩 끈 결과다(요약 `docs/evidence/reverse23_summary.txt`).

| 빈 | 23일 | 초기값 없이 | PR 고정 없이 | 필요한 조건 | 성공 해의 NLL − 대안 해의 NLL |
|---|---|---|---|---|---|
| fwd 1–2 | +0.14% | +30.2% | +0.14% | 이전 성공 fit 초기값 | +0.39 |
| fwd 2–3 | +0.66% | +23.3% | +23.3% | 초기값 + PR 구성비 2·3번 MC 고정 + 간격비 중심 3.6/12 | +9.05 |
| mid 7–8 | −0.82% | −0.82% | −0.82% | 없음 | 0 |
| mid 8–9 | +2.10% | +2.50% | +2.10% | 초기값 + 간격비 중심 2.5 | +0.51 |

수치 범위 파일은 영향이 없다. fwd 1–2는 B가 30% 다른 두 해가 NLL 0.39 차이로 공존한다.

## 5. 해석

- mid 7–9의 nominal 차이는 입력 데이터(acceptance cut)에서 나온다. old acc 입력에서는 9월 정책이 2% 안에 들어간다.
- 23일의 mid 8–9, fwd 2–3 결과는 PR 해상도 꼬리 간격을 MC의 1.3–2배로 강제하고, 이전 해에서 시작해 얻은 것이다. 같은 모형의 최소는 각각 +2.5%, +23.3%이다.
- nominal(엑셀)이 더 넓은 꼬리를 가진 해상도 모형(예: 사건별 오차 기반)으로 만들어졌을 가능성이 있으나 확인하지 못했다(설정이 서버에 없음).
