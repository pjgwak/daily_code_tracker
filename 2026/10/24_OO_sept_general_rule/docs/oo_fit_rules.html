PDF별 규칙으로 nominal B fraction 재현

mass–ctau 2D fit에서 각 PDF를 고정·제약·자유 중 어떻게 다룰지 정한 규칙 집합 FINAL_v3로 20개 빈을 한 번에 fit했다. 모든 fit은 MC prefit 값에서 시작하며, 이전 결과의 초기값이나 PR 고정은 쓰지 않았다.

요약: 경향과 전략

관찰된 경향
  1. B를 가장 크게 바꾸는 것은 prompt 해상도(PR) 모양을 MC에 얼마나 묶느냐이다. 배경·mass 모형, prefit의 성분 수와 초기값, 개수/비율 매개변수화는 B를 1% 이상 움직이지 않았다.
  2. 데이터는 거의 모든 빈에서 PR core 폭을 MC보다 20–35% 넓게 원하지만, nominal은 core 폭이 MC에 가까울 때 재현된다. 신호 순도(S/B)가 낮은 빈일수록 PR을 MC에 강하게 묶어야 하고, 순도가 높아질수록 풀어도 맞는다.
  3. NP는 통계와 순도가 충분한 고pT에서만 가장 긴 수명을 데이터로 정하고, 나머지는 MC 공분산으로 묶을 때 안정적이다.
  4. 배경 ctau 모양은 sideband에서 정한다. 배경이 신호의 약 10배인 forward 1–5 GeV에서만 그 값에 제약해야 한다.
  5. 남은 예외 빈(mid 8–9, fwd 2–3)은 PR 꼬리를 MC보다 넓게 강제해야 맞는데, 데이터만으로는 오히려 MC보다 좁은 꼬리를 원한다. mid 7–9의 차이는 단일 뮤온 acceptance cut이 데이터에서 빼는 이벤트 때문이다.
전략 (한 문단)

질량 모양과 배경 해상도는 prefit에 고정하고, 신호의 prompt 해상도와 nonprompt 수명 분포는 MC prefit 값을 중심으로 하는 Gaussian 제약으로 다룬다. 제약 강도는 신호 순도와 통계에 따라 정한다. 순도가 낮은 forward 저pT에서는 해상도와 NP 모양을 MC에 강하게 묶고, 순도가 높아질수록 해상도 core 폭 제약을 단계적으로 풀고 가장 긴 NP 수명을 데이터로 정한다. 이 규칙으로 맞지 않는 네 빈(forward 2–3·7–8, mid 7–8·8–9)에서는 해상도 제약만 빈별로 조정한다.

전략 (상세)

신호와 배경의 질량 모양, 배경 ctau의 해상도는 각각의 prefit 값에 고정하고, 신호 수율·배경 수율·B는 자유롭게 둔다. 신호의 prompt 해상도(Gauss 합의 폭과 구성비)와 nonprompt 수명 분포는 MC prefit 값을 중심으로 하는 Gaussian 제약으로 다루며, 그 강도는 신호 순도(S/B)와 통계에 따라 정한다. forward 1–5 GeV(S/B ≈ 0.1)에서는 해상도 폭과 구성비, NP 모양을 모두 MC에 제약하고 배경 수명과 비중도 sideband fit 값에 제약한다. forward 5–10 GeV(S/B 0.24 → 1.2)에서는 해상도 구성비를 MC에 고정하고, core 폭은 순도가 오를수록 단계적으로 풀어 주며(5–7 GeV 고정, 8–10 GeV 폭 2.5 µm로 제약), NP는 가장 긴 수명만 데이터로 정한다. forward 10–20 GeV에서는 core 폭을 MC에 고정하고 바깥 꼬리 간격만 제약한다. mid 8–12 GeV에서는 해상도 폭과 구성비, NP 모양을 MC에 제약하고, mid 12–30 GeV에서는 NP의 가장 긴 수명만 데이터로 정한다.

이 그룹 규칙으로 nominal과 맞지 않는 네 빈에서는 해상도 제약만 빈별로 조정한다. forward 7–8 GeV에서는 core 폭을 고정하지 않고, MC 값을 중심으로 이웃 두 단계 사이인 0.4 µm 폭으로 제약한다. mid 7–8 GeV에서는 해상도의 평균·폭·구성비를 MC 통계 오차의 8배 폭으로 함께 제약한다. mid 8–9 GeV와 forward 2–3 GeV에서는 해상도 꼬리 간격과 core 폭의 비를 각각 MC 값의 1.5배, 2.4배를 중심으로 제약하고, forward 2–3 GeV는 해상도 구성비도 MC 값에 고정한다.

확인한 사항

  • mid 7–9의 차이는 입력 데이터에서 온다. 9월 정책에 old acceptance 데이터를 넣으면 9월 결과(mid 8–9 +1.06%)가 그대로 재현되고, prefit을 바꿔도 0.3% 이내로만 변한다. new acceptance 데이터에서는 같은 정책이 mid 7–8 −4.2%, 8–9 +4.9%를 준다. mid nominal(7/27)은 단일 뮤온 cut이 없는 데이터 기준이다.
  • 23일 결과 중 세 빈은 같은 모형의 최소점이 아니다. fwd 1–2, fwd 2–3, mid 8–9는 이전 성공 fit에서 시작하거나 PR 구성비를 고정해야 재현되며, 실제 최소는 각각 +30.2%, +23.3%, +2.5%이다.
  • fwd 1–2에는 거의 같은 우도의 해가 둘 있다. B가 30% 다른 두 해의 NLL 차이가 0.39이다. 이번 결과(+0.5%)도 그중 한쪽이다.
  • MC prefit 오차는 통계 오차뿐이다. MC PR fit 범위만 바꿔도 매개변수가 통계 오차의 2–15배 움직인다. 이 모형 오차를 넣고 배율 튜닝 없이 제약하면 20빈 중 6–7빈만 통과한다.
  • B에 영향이 작았던 것. 배경 ctau 성분 구성, sideband 한쪽만 사용, 배경 해상도 해제, mass 모양 해제, mass 배경 1–3차, prefit 성분 수·초기값 변형(fwd 7–8), 개수/비율 매개변수화는 모두 1% 이내였다.
  • NP 꼬리. mid 8–10에서 데이터 신호의 꼬리 비율 N(1–4 mm)/N(0.3–1 mm)이 MC보다 약 2σ 작다(mid 8–9: 0.158 ± 0.023 vs 0.203). sideband 차감에 의존하는 측정이다.

한계

  • 그룹 경계와 제약 강도는 nominal 비교를 보며 정했다. fit 오차는 선택한 모형과 제약에서의 통계 오차이며, 규칙 선택에 따른 계통 오차는 포함하지 않는다.
  • mid 8–9와 fwd 2–3은 PR 꼬리 간격 제약의 중심을 MC 값의 1.5배, 2.4배로 옮긴 결과다. 이 값은 MC도 데이터도 지지하지 않는다.
  • mid 8–9는 2% 기준까지 여유가 0.13%p다.
  • mid nominal은 단일 뮤온 cut 없는 데이터 기준이라 mid 저pT 비교에는 입력 데이터 차이가 섞여 있다.
