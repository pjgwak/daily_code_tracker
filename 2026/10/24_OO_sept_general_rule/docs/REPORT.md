## 2. 모든 빈에 공통인 처리

| PDF (prefit) | final fit 처리 |
|---|---|
| 신호 mass (MC mass prefit: Gauss 1 + CB 2, CB 꼬리 MC 고정) | 모양 고정 |
| 배경 mass (DATA mass prefit, Chebychev 2차) | 모양 고정 |
| 배경 ctau (DATA sideband prefit) | 해상도 Gauss는 sideband 값에 고정. 수명·구성비는 자유(fwd 1–5는 sideband prefit 값에 제약) |
| 수율 Nsig, Nbkg, B | 자유. B ∈ [0, 1], nominal은 likelihood·초기값·제약 중심 어디에도 쓰지 않음 |
| ctau 범위 | 23일 window 스터디 값 (`study/review_20261024/`): fwd 1–3 [−4, 6.5], 3–5 [−3.5, 4.5], 5–10 [−1, 4], 10–20 [−0.5, 3], mid [−1, 4] mm |

배경 ctau 성분: mid pT < 12는 SS2 + DS1, mid pT ≥ 12는 SS1 + DS1(ΔBIC 기준), fwd는 23일 calibrated prefit(빈별 BIC 최선)을 쓰되 fwd 4–5는 SS2 + Flip1로 다시 정했다. fwd 1–5의 배경 해상도 Gauss 구성비는 sideband 데이터로 fit한다. 모든 prefit은 status 0, covQual 3이다.

**fwd 4–5 수정 (2026-10-25)**: 기존 MC PR prefit에 MC 꼬리 0.1%를 맞추려고 생긴 폭 1.65 mm의 Gauss가 있어, 배경 해상도가 ctau −3 mm까지 퍼지고 음의 꼬리 지수 성분이 0이 되었다(배경 prefit χ²/ndf 1.32). MC PR fit 범위를 0.2–99.8% 분위수로 좁혀 다시 fit하면 4번째 Gauss가 0.18 mm가 되고 (χ²/ndf 1.35 → 0.87), 배경은 세 지수 성분이 모두 쓰이는 SS2 + Flip1(χ²/ndf 0.87, 해상도의 가장 넓은 Gauss 0.19 mm)을 골랐다. 성분 선택은 BIC가 아니라 각 성분이 실제로 쓰이고 해상도가 피크 근처에 머무는지를 기준으로 했다. final B는 +1.59% → +1.53%이다.

## 3. 그룹별 규칙

PR 해상도의 폭 좌표는 σ₁(가장 좁은 Gauss)과 간격 Δ₂–Δ₄(σᵢ − σᵢ₋₁)이다. "제약"은 MC prefit 값을 중심으로 하는 Gaussian 제약이고, 괄호 안이 제약 폭이다.

|---|---|---|---|---|---|
| fwd 1–3 | 자유 | 제약 (0.08, 0.16, 0.32, 0.64 mm) | MC 공분산 제약 | 전부 제약 (MC 공분산 ×175) | sideband 제약 |
| fwd 3–5 | 자유 | 제약 (0.0012, 0.0024, 0.0048, 0.0096 mm) | MC 고정 | 전부 제약 (MC 공분산) | sideband 제약 |
| fwd 5–10 | 자유 | core 폭 단계 제약: 5–7 고정, 7–8 (0.0004 mm), 8–10 (0.0025 mm) | MC 고정 | 가장 긴 수명 자유, 나머지 제약 | 자유 |
| fwd 10–20 | 자유 | core 폭 MC 고정, 바깥 두 간격 제약 (0.004, 0.008 mm) | MC 고정 | 가장 긴 수명 자유, 나머지 제약 (×16) | 자유 |
| mid 8–12 | 자유 | 제약 (0.0025, 0.005, 0.010, 0.020 mm) | MC 공분산 제약 | 전부 제약 (MC 공분산) | 자유 |

fwd 5–10의 core 폭 제약은 신호 순도 S/B가 커질수록 느슨해진다(S/B: 5–6 0.24, 6–7 0.42, 7–8 0.69, 8–9 0.95, 9–10 1.20). 순도가 낮으면 prompt 영역의 신호 core 폭과 배경 prompt형 성분을 데이터로 나누기 어려우므로 MC에 묶는다는 해석이다. 같은 경향을 연속식 s₁ = 0.0011 mm × (S/B)²로 써도 5/5 통과한다.

| fwd 2–3 | +32.3% | PR 구성비 MC 고정, 간격비 q₃·q₄ 제약 중심 **2.4 × MC**(4.25 / 11.7), NP 평균 수명 제약, 배경 sideband 제약 ×4 | −0.09% |
| fwd 7–8 | +3.6% (core 고정) / −4.2% (폭 ×0.25) | fwd 5–10 단계 규칙 안에서 이 빈만 core 폭 제약 0.0004 mm | +0.14% |

- **mid 7–8**: 공분산 ×64는 제약 폭이 MC 통계 오차의 8배라는 뜻이다(σ₁ 기준 26%, 첫 구성비 95%). fit에서 가장 좁은 Gauss의 비중이 48% → 7%로 줄어 성분이 재배치된다.
- **mid 8–9, fwd 2–3**: PR 해상도 꼬리 간격을 MC보다 넓게(1.5×, 2.4×) 강제한다. 데이터만으로 정한 간격비는 오히려 MC보다 작다(mid 8–9: 0.9–1.3 vs MC 1.96, fwd 2–3: q₃ 0.0·q₄ 2.8 vs 1.77·4.88). 넓은 PR 꼬리가 양의 ctau 쪽 NP형 이벤트를 prompt로 흡수해 B를 낮추는 효과다. 23일 GPT 해법도 같은 조건(중심 2.5, 3.6/12)에 의존했다.

## 5. 확인한 사항

1. **9월 정책 그대로 (S0)**: new acc에서 10/20 통과.
2. **new acceptance cut의 영향**: 9월 정책으로 데이터와 prefit을 엇갈려 바꾼 결과, mid 7–9의 차이는 데이터에서 온다. old acc 입력에서는 9월 결과(mid 8–9 +1.06%)가 정확히 재현된다. mid nominal(7/27)은 cut 없는 데이터 기준이고, 모형 없이 센 NP 지표도 new acc에서 mid 7–8 −2.6%, 8–9 +3.7% 움직인다. → [MID79_FWD23.md](MID79_FWD23.md)
3. **배경·mass 모형**: 배경 ctau 성분 구성, sideband 한쪽만 사용, 배경 해상도 해제, mass 모양 해제, mass 배경 Chebychev 1–3차는 mid 8–9 B를 1% 이상 움직이지 않는다.
4. **prefit 스터디 (fwd 7–8)**: PDF 종류(신호 mass, PR Gauss 수, NP 성분 수, 배경 구성)와 초기값 10개 변형에서 B는 +3.0~+3.8%로 안정적이다. prefit은 개수, final은 비율로 쓰는 매개변수화 차이도 0.1% 이내다.
5. **MC 제약 오차**: MC prefit 오차는 통계뿐이다. MC PR fit 범위만 바꿔도 매개변수가 통계 오차의 2–15배 움직인다. 이 모형 오차를 넣은 제약(√(통계² + 모형²), 배율 튜닝 없음)으로는 20빈 중 6–7빈만 통과한다. nominal을 재현하려면 위 규칙처럼 그룹·빈별 강도 선택이 필요하다는 뜻이다.
6. **23일 결과 역추적**: 23일 결과 중 fwd 1–2, fwd 2–3, mid 8–9는 이전 해에서 시작하거나 PR 구성비를 고정해야 재현된다. 같은 모형의 실제 최소는 각각 +30.2%, +23.3%, +2.5%이다. fwd 1–2는 B가 30% 다른 두 해가 NLL 0.39 차이로 공존한다. FINAL_v3의 fwd 1–2(+0.5%)도 이 두 해 중 하나이다.
7. **NP 꼬리**: mid 8–10에서 데이터 신호의 꼬리 비율 N(1–4 mm)/N(0.3–1 mm)이 MC보다 작다(mid 8–9: 0.158 ± 0.023 vs 0.203). sideband 차감에 의존하는 측정이다.

## 6. 한계

- 그룹 경계와 제약 강도는 nominal 비교를 보며 정했다. fit error는 선택한 모형·제약 조건에서의 통계 오차이며, 규칙 선택에 따른 계통 오차는 포함하지 않는다.
- mid 7–8, mid 8–9, fwd 2–3, fwd 7–8은 빈별로 정한 설정이다. 특히 mid 8–9와 fwd 2–3은 PR 꼬리 간격 제약의 중심을 MC 값의 1.5배, 2.4배로 옮겼다.
- mid 8–9는 2% 기준까지 0.13%p 여유뿐이다(+1.87%). 중심을 1.63×MC로 하면 +1.52%이다.
- fwd 1–2는 B가 다른 두 해가 거의 같은 우도를 가진다.
- mid nominal은 단일 뮤온 cut 없는 데이터 기준이라, mid 저pT 비교는 입력 데이터 차이를 포함한다.

## 7. 재현

```bash
bash run_ctau_bins.sh          # prefit 5단계 + 최종 2D fit (FINAL_v3)
bash run_ctau_bins.sh --2d     # 최종 2D fit만
bash run_publish.sh            # 발표용 그림
```

빈별 prefit 선택은 `config/prefit_settings.txt`, 최종 2D fit 설정은 `study/rules/FINAL_v3/`에 있다. 그룹 규칙의 정의는 `study/rules.py`(`FINAL_v1`)이고, `FINAL_v3`은 여기에 mid 8–9(간격비 중심 1.5 × MC)·fwd 2–3(2.4 × MC) knob을 넣은 것이다. 중간 버전 FINAL_v2는 mid 8–9에서 NP를 완전히 자유로 두어 신호 NP의 15%가 ctau 범위 밖에 놓였기 때문에(경계 조건 위반) 채택하지 않았다.

ctau 범위의 근거 문서(23일 window 스터디)는 `study/review_20261024/`에 있다. 최종 결과는 이 폴더만으로 다시 만들 수 있다.
