# 구간별 적합 설정

검토 대상은 `recovery_candidate20_exact_starts_g7 / D7_Recovery_candidate20`이다. 수치는 해당 실행에 저장된 설정과 실제 제약 목록을 기준으로 한다. “자유”는 적합 변수임을 뜻하며 제약의 유무와 구별한다. 이 표의 PR 고정값은 MC prefit에서 가져온다. NP 수명을 고정한 빈은 없다.

## 매개변수와 제약의 표기

PR 폭 좌표는 w = (σ₁, Δ₂, Δ₃, Δ₄), Δᵢ = σᵢ − σᵢ₋₁이다. 아래의 폭 제약 표준편차는 이 좌표에 적용하며 전체 Gaussian 폭 σᵢ에 각각 직접 적용하는 값이 아니다. 성분이 세 개이면 사용하지 않는 네 번째 좌표는 제외한다.

Gaussian 제약은 ΔNLL = ½(θ−θ₀)ᵀV⁻¹(θ−θ₀)이다. 단일 매개변수의 경우 ½[(θ−θ₀)/s]²이다. 공분산 배율 k는 V→kV이고, 표준편차 배율은 √k이다. PR 폭 자체에 배율을 곱하는 것과 구별한다. 제약 조건 및 변수 범위를 변화시키며 적합 결과를 확인했고, 채택한 설정과 초기값을 저장했다.

공동 PR 제약의 구성비 표준편차에는 전체 scale을 포함했다. 즉 Forward 3–5는 1.25×0.3=0.375, Mid 8–9는 0.25×0.1=0.025이다. 이전 중간 문서의 scale 적용 전 수치와 구별한다. Mid 8–9 설정 파일에 남아 있는 `np_cov_scale=2048`은 `np_constraint=0`에 의해 비활성이며 실제 NP 제약이 아니다.

Forward 10–14의 PR4에서는 σ₁·Δ₂를 고정하고 Δ₃·Δ₄를 적합한다. Forward 14–20의 PR3에서는 σ₁만 고정하고 Δ₂·Δ₃를 적합한다. 성분 수에 따른 같은 “꼬리 폭 좌표 두 개 자유” 규칙이다.

## 폭 간격비 제약

q₃ = (σ₃−σ₂)/σ₁, q₄ = (σ₄−σ₃)/σ₁에 Gaussian 항을 적용한다.

## Mass·배경 설정

신호와 배경 mass 형상은 대응하는 prefit 값에 고정한다. 전체 신호 yield, 배경 yield, nonprompt fraction B는 적합한다. B는 [0,1] 범위에서 자유이며 기준 B를 중심으로 하는 제약이나 사후 B 환산은 적용하지 않는다.

Forward 1–2와 3–5에서는 배경 해상도 폭을 prefit 값에 고정하고 배경 수명·성분 yield에 sideband prefit 제약을 적용한다. 배경 제약 표준편차 배율은 1이다. 수명 좌표에는 코드에 지정된 최소 제약 표준편차가 함께 적용되므로 모든 오차가 sideband fit의 통계오차와 동일하다고 해석하지 않는다. 나머지 구간은 배경 해상도 core를 고정하고 꼬리·구성비를 적합한다.

sWeight를 이용한 신호 PR·NP 형상 고정은 현재 설정에 포함하지 않는다. PR 104개 좌표는 자유, 48개는 MC 고정이다. 사용되는 NP 좌표 71개는 모두 자유다. 이 개수에는 mass·배경 좌표를 포함하지 않는다.

## 초기값과 재현

Forward 1–2, 2–3 및 Mid 7–8, 8–9는 성공한 실행에 실제 입력했던 seed를 복원했다. Forward 2–3에서는 NP 좌표를 MC prefit 값으로 초기화했다. 이 네 빈의 초기값·초기 오차·범위·고정 상태가 해당 성공 실행과 일치함을 확인했다. 두 번째 전체 실행에서 20빈을 실제 재적합했으며 빈별 결과를 서로 다른 실행에서 골라 합치지 않았다.
