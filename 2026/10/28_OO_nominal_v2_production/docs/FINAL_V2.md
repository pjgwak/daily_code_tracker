## FINAL_S3 (25일 production)에서 바뀐 규칙

prefit은 바꾸지 않았다. 질량 창은 모든 빈에서 [2.6, 3.5] GeV 그대로다. PR 폭 좌표는 가장 좁은 Gauss 폭 σ₁과 간격 Δᵢ = σᵢ − σᵢ₋₁이고, 제약은 MC prefit 값을 중심으로 하는 Gaussian이다. 모든 PR 폭 제약의 폭은 MC prefit 오차 이상이다 (아니면 고정 또는 자유).

| 빈 | FINAL_S3 | FINAL_V2 |
|---|---|---|
| fwd 3–4 | 폭 제약 (0.0005, 0.001, 0.002, 0.004 mm) = MC 오차의 0.6배 안팎 | 폭 제약 = MC 오차 ×1 |
| fwd 4–5 | 같은 제약 (MC 오차의 0.4–0.7배) | σ₁, Δ₂ 고정, Δ₃·Δ₄ 제약 = MC 오차 ×1 |
| fwd 8–9 | 폭 제약 (0.0012, 0.0024, 0.004, 0.08 mm) | (0.0025, 0.005, 0.01, 0.08 mm) |
| fwd 10–12, 12–14 | σ₁, Δ₂ 고정, Δ₃·Δ₄ 제약 (0.004, 0.008 mm), Δ₄는 MC 오차의 0.54·0.77배 | Δ₄ 제약 = MC 오차 ×1 (0.0147, 0.0104 mm) |
| mid 전 빈 | PR 평균 MC 고정, 폭 제약 (0.01, 0.02, 0.04, 0.08 mm), 가장 긴 NP 수명만 자유 | PR 평균 자유, 폭 제약 (0.0025, 0.005, 0.01, 0.02 mm), NP 수명 전부 자유 |

fwd 1–5의 PR 폭 처리는 pT가 오를수록 단계적으로 묶인다: 1–2 제약 (0.02, 0.04, 0.08, 0.16 mm), 2–3 자유, 3–4 MC 오차 ×1 제약, 4–5 core 고정 + 꼬리 MC 오차 ×1, 5–8 core 고정 + 꼬리 (0.01, 0.02 mm).
