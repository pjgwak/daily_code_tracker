요약

관찰된 경향
  1. 24일 규칙(FINAL_v3)을 이 입력에 그대로 쓰면 12/20만 통과한다. 다른 입력에서 정한 제약 강도는 그대로 옮겨지지 않는다.
  2. B를 가장 크게 움직이는 것은 이번에도 prompt 해상도(PR)를 MC에 묶는 방식이다. fwd 3–5에서는 폭 제약 배율 하나로 B가 −8%에서 +5%까지 단조롭게 움직인다.
  3. mid는 9월 mid 정책과 같은 구조(PR 평균·구성비 MC 고정, 폭 제약, 가장 긴 NP 수명 자유) 하나로 8빈이 모두 맞는다.
  4. fwd 10–20은 어떤 규칙과 prefit에서도 B가 nominal보다 낮았고, PR 꼬리 간격을 MC보다 좁게 제약할 때만 맞는다.
  5. fwd 2–3은 ctau 창 [−4, 6.5]에서는 MC 중심 제약으로 맞지 않았다(간격비 중심을 1.8 × MC로 옮겨야 +0.88%). 10/26 Codex 탐색이 찾은 설정(창 [−20, 20] mm, 배경 sideband prefit의 짧은 수명 범위 확장, NP 1성분 유효 수명을 MC 평균에 제약)은 MC 중심 제약만으로 +2.96%이고 이것을 채택했다. Codex가 추가로 쓴 mass 배경 2차(+2.35%)는 적합도가 나빠져 쓰지 않았다.
  6. prefit을 다시 본 결과 세 가지를 바꿨다. fwd 10–20의 NP 두 번째 성분이 퇴화해 1성분으로 줄였고, fwd 5–6은 PR MC fit 범위를 좁혔다. 둘 다 prefit 품질이 좋아지는 변경이다. fwd 2–3은 창과 배경 성분을 바꿨다(이전 prefit은 짧은 배경 수명이 하한).

prefit을 다시 본 결과

  • fwd 10–20 NP 성분 2 → 1. MC NP prefit의 두 번째 성분이 퇴화해 있었다(10–12 yield 62 ± 72, 12–14 오차 > 값, 14–20 수명 하한). 2성분에서는 fwd 12–14 B가 +11.8%, 오차가 다른 빈의 2배였다. 1성분 prefit χ²/ndf는 0.81, 1.02다.
  • fwd 2–3 창·배경·mass 배경 (10/26). ctau 창 [−4, 6.5] → [−20, 20] mm, 배경 sideband prefit 2/1/1 → 2/0/1에 짧은 수명 범위를 넓게 열어 core 폭 0.0728 mm 해(9월 sideband 해와 같은 국소 최소, χ²/ndf 0.98). Codex 10/26 탐색의 재현이며, 2D 규칙도 NP 유효 수명 제약·PR 폭 자유로 바꿨다.
  • fwd 5–6 PR MC fit 범위 축소. 0.05–99.95% → 0.2–99.8% 분위수(24일 fwd 4–5와 같은 처리). PR χ²/ndf 1.27 → 1.03, 배경 0.74 → 0.59, 가장 넓은 Gauss 0.25 → 0.14 mm.
  • 거부된 변형. NP 1성분(fwd 3–6, mid 7–8), PR Gauss 3개(5빈), mass 배경 1차(fwd 3–5)는 prefit χ²/ndf가 2를 넘어 fit2d의 품질 검사에서 거부됐다.
  • B만 맞는 변형은 쓰지 않았다. fwd 4–5 PR Gauss 3개(−0.62%, PR χ²/ndf 1.13 → 1.80), fwd 10–12 배경 SS1+DS1(+0.10%, robust χ²/ndf 2.3 → 4.6).
  • fwd 10–12 배경 prefit. 짧은 배경 수명과 해상도 core 폭이 상한 근처에 있었지만, 상한을 풀어도 prefit과 B가 바뀌지 않았다(−2.93% → −2.92%). ctau 범위를 넓혀도 −2.7~−2.9%다. 차이는 PR 해상도 처리에서 온다.

한계

  • 그룹 경계와 제약 강도는 nominal 비교를 보며 정했다. fit 오차는 선택한 모형과 제약에서의 통계 오차이며, 규칙 선택에 따른 계통 오차는 포함하지 않는다.
  • fwd 10–20은 PR 꼬리 간격비 제약 중심을 MC의 0.4배로 옮긴 결과다. 0.4배는 수렴하는 범위의 끝이다.
  • fwd 1–2, 2–3은 빈별 설정이다. fwd 2–3은 ±2% 밖(+2.96%, 0.41σ)이며 잠정 결정이다. 2% 안에 넣으려면 off-MC 중심이나 B만으로 정당화되는 mass 배경 2차가 필요해 쓰지 않았다. fwd 1–2는 nominal 오차가 커서(σnom 0.014) 0.138σ 기준이 넓다.
  • forward nominal(Excel)은 pp_HX 단일 뮤온 acceptance로 만든 값으로 알려져 있고, 이 입력의 JunChen acceptance와 같은 정의인지는 확인하지 않았다.
